# DnD Roguelike

ASCII-рогалик с упрощёнными механиками D&D 5e на Python + `tcod`.

![Python](https://img.shields.io/badge/Python-3.12-blue)
![tcod](https://img.shields.io/badge/tcod-21.2.0-green)

## Возможности

### Персонаж
- Класс **Воин (Fighter)**: Боевой стиль (Защита), **Второе дыхание** (1d10 + уровень HP, раз за бой).
- Ввод имени в начале каждого забега (поддержка кириллицы).
- Прокачка: XP → Level up → больше HP и бонус мастерства.
- Экипировка: оружие, броня, щит (влияют на AC, урон, тип урона).
- Инвентарь: зелья лечения, свитки заклинаний.
- Экран персонажа: все характеристики, умения, снаряжение.

### Мир
- Процедурная генерация подземелья: комнаты + L-образные коридоры.
- Несколько этажей (с подтверждением спуска: «Перейти на этаж N?»).
- FOV (поле зрения): видны только освещённые клетки; исследованные — в тени.
- Сохранение при выходе (Permadeath: сейв удаляется при гибели).

### Монстры (5 видов + уникальные черты)
| Монстр    | Черта          | Эффект                                           |
|-----------|----------------|--------------------------------------------------|
| Гоблин    | —              | Слабый, часто встречается                        |
| Скелет    | `undead_resist`| Режущий/колющий урон уполовинен                  |
| Волк      | `pack_tactics` | Атака с преимуществом, если есть живой союзник   |
| Слизь     | `acid_splash`  | Кислотный контрудар (1 урон) по ближнему бойцу  |
| Орк       | `rage_at_half` | При падении до 50% HP впадает в ярость: +2 к атаке |

- До 3 монстров за бой; не более 1 орка за схватку.
- **Kill-heal**: каждая победа над монстром возвращает ~20% его max HP.

### Бой (JRPG-стиль)
Механика D&D 5e: `d20 + мод + профбонус` vs AC, криты на 20, фамблы на 1.

| Клавиша | Действие      |                                                        |
|---------|---------------|--------------------------------------------------------|
| `A`     | Атака         | По выбранной цели                                      |
| `D`     | Защита        | Все атаки по тебе с помехой до следующего хода         |
| `S`     | Второе дыхание| Лечение 1d10 + уровень (один раз за бой)               |
| `I`     | Предмет       | Открыть меню расходников                               |
| `T`     | Цель          | Переключить цель; `1`–`3` — прямой выбор               |
| `F`     | Побег         | Проверка DEX vs DC (зависит от CR противников)         |

Статус-индикаторы во время боя: `❄` (заморожен), `ЯРОСТЬ` (орк), `СТАЯ` (волки с союзником).

### Предметы
- **Зелье лечения** — восстанавливает 2d4+2 HP.
- **Свиток «Волшебные стрелы»** — 3 стрелы по 1d4+1 (всегда попадают).
- **Свиток «Луч заморозки»** — 1d8 урона + заморозка цели на ход.
- **Свиток «Щит»** — блокирует следующую атаку по тебе.

### Случайные события (энкаунтеры)
Сундук/мимик, Торговец, Проситель, Алтарь благословений, Костёр отдыха.

## Управление

**Исследование**

| Клавиши              | Действие              |
|----------------------|-----------------------|
| `↑↓←→` / `hjkl`     | Движение (4 стороны)  |
| `y u b n`            | Диагонали             |
| `.`                  | Пропустить ход        |
| `i`                  | Инвентарь             |
| `c`                  | Лист персонажа        |
| `q` / `Esc`          | Сохранить и выйти     |

**Переходы между этажами**

При наступлении на `>` появляется диалог подтверждения. `Y`/`Enter` — перейти, `N`/`Esc` — остаться.

**Энкаунтеры:** `1`–`5` выбрать вариант; `Enter`/`Space`/`Esc` — закрыть результат.

## Структура проекта

```
DnD_Game/
├── main.py               # Точка входа, tcod context, game loop
├── data/                 # JSON-контент
│   ├── monsters.json
│   ├── weapons.json
│   ├── armors.json
│   ├── consumables.json
│   └── encounters.json
├── dnd_game/
│   ├── core/             # dice (d4–d20, roll expression), RNG seed
│   ├── rules/            # Чистая логика D&D: mod(), make_attack(), saving throw
│   ├── items/            # Weapon, Armor, Consumable + JSON-лоадеры
│   ├── entities/         # Character, Monster (без импорта tcod)
│   ├── world/            # Tile, Dungeon, генератор (BSP + коридоры), FOV
│   ├── encounters/       # Определения и активные энкаунтеры
│   ├── combat/           # CombatEngine — пошаговый бой
│   ├── game/             # Game state machine, save/load
│   └── ui/
│       ├── renderer.py   # Диспетчер рендеринга по GameState
│       ├── input_handler.py
│       ├── colors.py
│       └── screens/      # name_entry, combat, inventory, character,
│                         # encounter, stairs_prompt, game_over
└── tests/                # pytest (13 тестов)
```

**Архитектурный принцип:** `rules/`, `entities/`, `world/`, `combat/` не импортируют `tcod` — UI можно заменить без правок логики.
