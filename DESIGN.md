# DnD Roguelike — Design Roadmap

## Диагноз исходного состояния

Корень проблемы беспомощности против толпы — **action economy**: игрок делает 1 действие по 1 цели за ход, а до 3 врагов бьют все сразу. `kill_heal` (~20% HP за труп) был единственным костылем.

Бой плоский из-за хардкод-веток в engine, ad-hoc полей статусов, и единственного выбора «атакуй пока не упадёт».

Исследование статично: монстры-статуи, нет лута на полу, нет ловушек/дверей/секретов.

---

## Phase 0 — Фундамент (невидим, тесты зелёные)

- `entities/combatant.py` — общая база HP/statuses/resources для Character и Monster
- `rules/status.py` — единая система статусов с хуками on_apply/on_turn_start/on_expire
- Миграция `Character`: ad-hoc поля (dodge_active, shield_active, blessed_turns, second_wind_used) → statuses/resources
- Миграция `Monster`: frozen_turns, enraged → statuses
- Focus resource: 0→max(3+lvl//2), +1 на попадание, +2 на убийство

## Phase 1 — Анти-толпа (самый ощутимый игроком выигрыш)

### Новые боевые действия

| Клавиша | Действие | Стоимость |
|---------|----------|-----------|
| `W` | **Размах** — атака по ВСЕМ врагам (пол-урона по не-основным) | 2 Focus |
| `R` | **Рипост** — стойка: контратака по каждому, кто ударит тебя | 1 Focus |
| `P` | **Подсечка** — атака + цель проходит СИЛ спасбросок DC 13 или оглушается | 1 Focus |
| `U` | **Action Surge** — ещё одно полное действие в этот ход | 0 (1×/бой) |

### Масштаб урона
- **Extra Attack** (уровень 5): два удара за одно действие `[A]`
- Уточнённый `kill_heal` с учётом CR врага

## Phase 2 — Глубина боя

### Порядок ходов (CTB Timeline, Final Fantasy X-style)
- Каждый участник имеет `speed = max(1, 3 + dex_mod)`, задержка = `100 / speed`
- Быстрые (высокий DEX) ходят чаще; волки/гоблины быстрее игрока
- Слизь (DEX 6) ходит очень редко
- UI: полоса «Следующие 7 ходов» вверху экрана боя

### Слабости и сопротивления (data-driven)
- `monsters.json`: `resistances`, `vulnerabilities`, `immunities` по типу урона
- Скелет: уязвим к дробящему, резист к рубящему/колющему
- Слизь: уязвима к огню/cold, иммун к кислоте
- Гоблин: уязвим к огню

### Стойкость и Перелом (Break)
- `poise / max_poise` на каждом монстре
- Урон по слабостям снижает Стойкость
- При Стойкость=0: `staggered` (пропускает ход, получает двойной урон)
- После срабатывания Стойкость сбрасывается

### Телеграф намерений (Slay the Spire style)
- Каждый монстр показывает **следующее действие**: «Орк → ТЯЖЁЛЫЙ УДАР» / «Волк → УКУС» / «Скелет → ЗАЩИТА»
- Выбирается из `intent_pool` в начале хода, обновляется после атаки

## Phase 3 — Способности и прогрессия

### data/abilities.json — манёвры воина
Каждый манёвр: `cost`, `targeting`, `effects[]`, `description_ru`

| Манёвр | Эффект |
|--------|--------|
| sweep | Атака всех (уже в Phase 1, теперь через abilities.json) |
| riposte | Контратака при получении удара |
| trip | Подсечка + оглушение |
| heavy_strike | +2d6 урона, -2 к броску атаки |
| menace | Все враги получают `weakened` (помеха атакам) |
| cleave | Избыточный урон переходит на следующего врага |
| battlecry | +3 Focus, вся группа врагов теряет 1 Стойкость |

### Экран выбора при level-up
- Уровень 2: Action Surge (авто)
- Уровень 3: выбор из 3 манёвров
- Уровень 4: +2 к характеристике ИЛИ манёвр
- Уровень 5: Extra Attack (авто)
- Уровень 6: выбор манёвра
- Уровень 7+: чередование +2 характеристика / манёвр

## Phase 4 — Исследование интереснее

### ИИ монстров (world/ai.py)
- **IDLE**: патруль в случайном направлении
- **ALERTED**: движение к игроку по кратчайшему пути (BFS)
- Переход IDLE → ALERTED при обнаружении в FOV (radius 6)
- Шум боя стягивает монстров из соседних комнат

### Лут на полу
- Монстры оставляют дроп по `loot_table` в monsters.json
- Клавиша `G` поднять предмет (отображается `$` на полу)
- Редкость по CR: гоблин = монеты, орк = оружие/броня

### Ловушки
- Новый тип тайла `^`
- Проверка ЛВК DC 12 при наступлении — провал = 1d6 урона
- Вор/внимательный персонаж видит заранее

### Двери и секреты
- Тайл `+` (дверь): блокирует видимость, открывается ударом
- Секретные комнаты: один из тайлов стены ломается при взаимодействии
- Рычаги открывают отдалённые двери

### Свет / Факел
- Начальный FOV radius = 8 (факел)
- Без факела = radius 4, монстры не видны заранее
- Факелы как расходник (горят N ходов)

### Биомы и мини-боссы
- Этаж 5: тема «Катакомбы» — нежить доминирует, мини-босс Костяной Рыцарь
- Этаж 10: тема «Логово» — орки+волки, мини-босс Вождь Орков
- Мини-босс оставляет реликвию (пассивный бонус)
